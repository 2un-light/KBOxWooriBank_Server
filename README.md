## ⚾ KBOxWooriBank_Server

### 프로젝트 소개
KBO와 은행의 스폰서쉽을 통해 다양한 이벤트를 개최함으로써 사용자에게 야구 엔터테인먼트와 함께 금융 경험을 제공하는 프로젝트 입니다.

안정적이고 확장 가능한 서비스를 목표로 AWS 기반 인프라를 설계하고, 무중단 배포 환경을 구축하였습니다.
  
<br><br>

## 🚀 주요 기능
- 경기별 이벤트(승부예측, 퀴즈, 선착순)를 통한 포인트 및 경품 지급
- 야구 뉴스, 경기 일정, 구단 순위 등의 정보 제공
- 일반 사용자와 관리자 권한 분리 및 사용자 통계 시각화
- CSV 업로드를 통한 퀴즈/이벤트 등록 기능
